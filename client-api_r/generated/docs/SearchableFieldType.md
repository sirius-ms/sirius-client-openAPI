# RSirius::SearchableFieldType

Value type of a searchable field. Determines which query clauses are valid for the field:  TEXT supports terms, phrases, wildcards and regular expressions; numeric types (INTEGER, LONG, DOUBLE,  FLOAT), DATE (yyyy-MM-dd) and TIME (HH\\:mm\\:ss) additionally support comparisons and range queries;  BOOLEAN matches true/false; ENUM matches one of the possibleValues.
